  1. {{ $d.servizio.nome }} si apre in una nuova scheda. Il sito è in inglese: se vuoi, usa la funzione «Traduci» del browser.

  3. Se il sito chiede l'unità di misura, scegli millimetri (mm). Controlla che fra le misure indicate ci sia {{ $o.lunghezza_mm }} mm, la più grande: se non c'è, l'unità è sbagliata. Il file è già girato nella posizione giusta per la stampa: non serve cambiarla.
