{{/* Grafico interattivo accessibile da un file in data/ (14/10/2026, bilancio della campagna antincendio; v2 il 15/10/2026). "racconti" (giorno -> pagine) porta nel dettaglio del giorno il link all'articolo, col titolo letto dalla pagina a ogni build; può anche essere il nome di un altro file di data/ che contiene la stessa mappa (open data: "racconti_interventi"). "testi" (facoltativo) cambia le parole per il periodo intero: tutto ("tutta la campagna") e rivivi ("Rivivi la campagna giorno per giorno"). Senza JavaScript il grafico resta leggibile: barre e valori sono HTML, il calendario ha la tabella dei giorni con interventi.
