# Campagna Lazio 2026 — cartella di lavoro social

Materiale operativo per la campagna reclutamento **"Non c'è Protezione Civile senza di te"** (Regione Lazio, kit giugno 2026) sui canali del Gruppo di Genzano.

## File in questa cartella
- **`PIANO-CAMPAGNA.md`** — strategia, contatti, calendario 4 settimane, inventario asset, checklist, nota TikTok.
- **`CAPTION-PRONTE.md`** — caption copia-e-incolla per ogni asset, con alt text e CTA corrette.
- **`PIANO-UGC.md`** — copioni per i contenuti girati da noi alla sede.

## Dove sono i file grafici/video
Gli asset pronti (caroselli PNG, reel/TikTok MP4, banner, spot) sono nella cartella
`~/Scrivania/social regione lazio/PRONTI-DA-PUBBLICARE/`.
Sono materiali **della Regione**: si pubblicano integri (non si applica la regola dei "4 loghi" del Gruppo).
