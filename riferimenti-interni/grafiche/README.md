## Regole

1. Prima di pubblicare una di queste grafiche, ricontrollare la coerenza araldica
   (stemma, iniziali, colori) con il logo ufficiale.
2. Le regole di composizione istituzionale (4 loghi, ESC + codice E10435833)
   valgono solo per le grafiche di comunicazione ufficiale, non per le immagini
   illustrative inline; queste ultime seguono le regole foto (`{{< foto >}}`,
   alt/caption oneste).
